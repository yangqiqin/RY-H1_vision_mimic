## 二、逐项借鉴与取舍
### 1) Real-time-3D-control…（借鉴度最高）
- **多进程流水线解耦**：采集/检测/IK 各自进程+队列。
  → 借鉴为**本项目后台 worker 线程一条流水**（采集在 capture 线程、检测+IK+执行在 worker、
  主线程只显示）。已落地；若检测继续成为瓶颈，再拆独立线程/进程。
- **RealtimeSmoother3D**：α≈0.3；单帧突变(2D>0.2 / 深度差>0.1)先压幅再 EMA，**不丢帧**。
  → 借鉴改造 follower 手腕平滑：EMA_OUTLIER_M=0.15 突变先压缩 30% 再 EMA(α=0.35)，
  每轴 2mm 死区。已落地（arm_follow_eye）。
- **面积→深度估计**：单目无深度时用掌面积换算。
  → **不采用**：本项目用 L515 有真实深度，直接量测更准；保留作"深度大面积失效"的备选思路。
- **DexPilot 手部重定向(MANO/手掌多边形)**：手形到灵巧手。
  → 借鉴思路（现用手部 21 点→16 关节角映射已够用）；后续可换 MANO 提升手形精度。

### 2) 视觉伺服论文（PBVS/IBVS、手-臂遥操作）
- 共同结论：**误差=期望-当前 → 直接作用于速度/关节**（而非"路径点执行"）；
  运动映射前滤波；**预判/预测可补偿延迟**。
  → 本项目按 **PBVS（位置基）** 取舍：期望末端=锚点+手腕平滑位移，固定姿态→IK→
  **servoJoint 实时下发**（已落地修改22）；move 队列只保留为降级模式。
  → 延迟预算与参数见《实时跟随servo方案与参数指南.md》。

### 3) 动作识别/预测（夏莹昕等）
- 意图识别+预测可在 0.1s 视觉环外做"前瞻/减振"（对未来 100~300ms 趋势预测平滑目标）。
  → 路线图项（非主链必需）；等实时环稳定后再加一阶/二阶预测器。

### 4) 手部关键点增强（IR/增强）
- 红外/低质图像增强或数据增强提升检测稳定性。
  → 暂不引入（L515 RGB 环境已可用）；若实机检测不稳再评估轻量 ROI 跟踪。

## 三、取舍原则
1. **流畅/实时优先，精度其次**（用户明确）；
2. 执行层用 **servoJoint**（实时），move 为降级；
3. 检测保持"原分辨率 + 每帧处理，只丢弃旧帧不跳过等待"；
4. 平滑"压缩异常+EMA+死区"，**绝不因深度差丢帧/急停**；
5. 所有保护（丢手时间制/力矩/姿态硬锁/高度安全区/锁腕已移除敏感项）只拦"真危险"。
