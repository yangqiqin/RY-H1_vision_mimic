## 3. 硬件连接与开机

### 3.1 连接
1. **机械臂控制柜**上电（24V/48V 直流或 AC 按机型；K5 以官方文档为准）；
2. **网线**：电脑网口 ↔ 控制柜网口（直连，或同交换机）；
3. 确认电脑 IP 与控制柜同网段（如控制柜 `192.168.1.200`，电脑设 `192.168.1.100`，
   掩码 `255.255.255.0`）；或用示教器查看控制柜实际 IP；
4. **灵巧手**：RY-H1(16) 若安装在机械臂末端法兰，供电与通信仍走原有 PCAN/RS485 链路（独立于机械臂）。

### 3.2 开机顺序（建议）
```
控制柜上电 → 电脑网络就绪 → 打开示教器确认机械臂模式(Idle/PowerOff) → 运行本工程连接 → 上电+启动(松刹车)
```

> ⚠️ **首次务必**：机械臂周围留出安全空间、附近无人、急停按钮可触及；
> 先 `apps/test_arm.py`（仅连接+读状态）确认通信，再做任何运动。

## 4. 机械臂模块说明（arm/）

### 4.1 `arm/arm_config.py` —— 配置单点

| 键 | 默认值 | 说明 |
|---|---|---|
| `ip` | `192.168.1.200` | 控制柜 IP（改这里或命令行 `--ip`） |
| `rpc_port` | `30004` | RPC 服务端口（官方示例） |
| `rtde_port` | `30010` | RTDE 数据端口（非阻塞/状态） |
| `username/password` | `aubo / 123456` | 登录账号（官方示例） |
| `speed_fraction` | `0.3` | **全局速度比例**（安全起步，官方示例 0.75） |
| `joint_speed/joint_acc` | `40°/s / 30°/s²` | moveJoint 速度/加速度（度，内部转弧度） |
| `line_speed/line_acc` | `0.4 m/s / 0.3 m/s²` | moveLine 线速度/加速度 |
| `blend_radius` | `0.0` | 过渡半径（0=精确到达） |
| `tcp_offset` | `[0,0,0,0,0,0]` | 基础工具中心点偏移（米/弧度） |
| `hand_mount_offset` | `[0,0,0.15,π,0,0]` | **灵巧手安装偏移**（TCP 联动核心，需实测） |

### 4.2 `arm/arm_controller.py` —— `AuboK5ArmController`

| 方法 | 说明 |
|---|---|
| `open()` / `close()` | 连接+登录 / 登出+断开 |
| `has_connected()` / `has_logined()` | 连接/登录状态 |
| `poweron()` / `startup()` / `poweroff()` | 上电 / 启动(松刹车) / 断电 |
| `poweron_and_startup(wait_running=True)` | 上电+启动，等待进入 Running |
| `get_robot_mode()` / `get_safety_mode()` | 模式 / 安全模式（RobotModeType 等） |
| `is_steady()` / `is_within_safety_limits()` | 是否停止 / 是否在安全限制内 |
| `get_joint_positions()` | 当前关节角（弧度，6 维） |

| `get_state_summary()` | 状态汇总（GUI/诊断显示） |
| `set_speed_fraction(f)` / `get_speed_fraction()` | 全局速度比例 0~1 |

| `movej(q, block=True)` | 关节运动（弧度） |
| `movel(pose, block=True)` | 直线运动（TCP 系，米/弧度） |
| `movec(mid, end)` | 圆弧运动 |
| `move_home()` | 回初始关节角 |
| `stop_move()` | 停止运动 |
| `servo_mode_enable(on, mode)` / `servo_joint(q)` | 关节伺服（视觉跟随/连续轨迹） |
| `freedrive(on, duration_s=None)` | 拖拽示教 |
| `get/set_standard_digital_*`、`get/set_tool_digital_*` | IO 读写 |
| `forward_kinematics(q)` / `inverse_kinematics(ref_q, pose)` | 正解 / 逆解 |

## 7. TCP 坐标联动（臂手联动）

### 7.1 原理
RY-H1(16) 灵巧手安装在机械臂末端法兰时，机械臂的"法兰坐标系"≠"灵巧手 TCP 坐标系"。
`setTcpOffset()` 告诉机械臂工具中心点的偏移，之后 `moveLine/moveCircle` 的位姿
就直接以**灵巧手 TCP**为基准：

```
机械臂法兰 ── 安装偏移(hand_mount_offset) ──▶ 灵巧手 TCP
    │                                              │
    └── setTcpOffset(基础偏移 + 安装偏移) ──────────┘
                 ▼
        movel([x,y,z,rx,ry,rz]) 的坐标 = 灵巧手 TCP 坐标
```

### 7.2 配置安装偏移（实测填写）
编辑 `arm/arm_config.py`：
```python
"hand_mount_offset": [0.0, 0.0, 0.15, 3.141592653589793, 0.0, 0.0],
#                     └x┘  └y┘  └z┘        └绕X轴180°┘
# 灵巧手在法兰下方 0.15m、倒装（绕X轴180°）——请按实际安装测量
```

### 7.3 启用方式
- **GUI**：勾选【TCP联动】→ 立即写入 setTcpOffset（含安装偏移）；
  取消勾选 → 恢复基础 TCP（偏移全 0）。
- **代码**：
  ```python
  from arm import AuboK5ArmController
  arm = AuboK5ArmController()
  arm.open()
  arm.apply_tcp_offset([0, 0, 0.15, 3.141592653589793, 0, 0])  # 启用联动
  arm.movel([0.5, 0.0, 0.4, 3.14, 0, 1.57], block=True)        # 位姿=灵巧手 TCP
  arm.close()
  ```

### 7.4 臂手联动动作
GUI 的【到位后握拳/张开/放松】= `movel(输入位姿)` 成功后再调
`hand.close_hand() / open_hand() / relax()`，实现"先摆位、再抓手"。

> ⚠️ 联动时灵巧手手势幅度仍受 `hand/` 校准参数与安全范围约束（侧摆 ±20° 等）。

## 8. 控制模型与 API 速查

### 8.1 关节角与位姿
- **关节角**：6 维弧度 `[J1..J6]`；GUI 滑条按度显示，内部 `math.radians` 转弧度。
- **位姿**：`[x, y, z, rx, ry, rz]`；位置米、姿态弧度（RPY/ZYZ 由 SDK 定义）。

### 8.2 常用调用链
```python
from arm import AuboK5ArmController
arm = AuboK5ArmController(ip="192.168.1.200")
arm.open()                        # 连接+登录
arm.poweron_and_startup()         # 上电+启动
arm.set_speed_fraction(0.3)
arm.movej([0, -0.26, 1.74, 0.44, 1.57, 0], block=True)
arm.movel([0.55, 0.0, 0.4, 3.14, 0, 1.57], block=True)
arm.get_joint_positions()         # 读回
arm.close()
```

## 9. 安全规范（必读）

1. **上电/运动前**：确认机械臂周围无人、无障碍物；急停按钮可触及；
2. **首次运动**：速度比例 0.2~0.3，用 `test_arm.py --move` 小幅度验证方向；
3. **不要站在机械臂工作半径内**操作；
4. **断电前**：先停止运动、机械臂回到安全位（或断电保持位），再断电；
5. **灵巧手联动**：手势幅度仍遵守灵巧手安全范围（24V/8A、0xAA 限流、禁止强行掰手指）；
6. **拖拽示教**：仅在 Running 模式且确认安全时启用；结束立即关闭（freedrive False）；
7. **网络**：控制柜 IP 变更后同步改 `arm_config.py` 或命令行 `--ip`；
8. **故障**：出现 Error/ProtectiveStop → 立即停止 → 按示教器指引解除 → 不要强行运动。

## 10. 常见问题排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `import pyaubo_sdk` 失败 | SDK 未装/版本不符 | `pip install pyaubo-sdk==0.27.1rc4` |
| 连接超时/被拒绝 | IP/端口错、控制柜未开机、网段不通 | `ping <控制柜IP>`；检查网线/网段；示教器确认 IP |
| 登录失败 | 账号密码错 | 默认 `aubo / 123456`；示教器修改后同步 |
| `getRobotNames` 为空 | 控制柜未就绪 | 等待控制柜启动完成；重启控制柜 |
| 上电/启动未达 Running | 已运行 / 急停 / 安全条件不满足 | `diag_arm.py` 看模式；解除急停；确认机械臂未运行 |
| movej/movel 返回错误码 | 运动参数非法/超限/奇异点 | `arm._ret_text(ret)` 看 SDK 错误码；查 `share/doc/error_code.md` |
| movel 报奇异点/不可达 | 位姿超出工作空间 | 改用 movej（关节角）验证；减小位姿变化 |
| 机械臂不动但连接正常 | 未上电/未启动/速度比例=0 | 先 `poweron_and_startup`；确认速度比例>0 |
| GUI 机械臂面板不刷新 | 未连接 / RPC 卡顿 | 看状态标签；`diag_arm.py` 单独测连接 |
| 灵巧手+机械臂同时用 | 两者独立链路 | 灵巧手走 PCAN/RS485，机械臂走网线 RPC，互不干扰 |
| 参考代码路径报错 | `lib/参考代码/` 被移动 | `lib/camera_lib1.py` 是转发模块，自动把 `参考代码/` 加入 sys.path |
